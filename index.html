C# Windows Forms Kod Rehberi

Visual Studio temel örnek kodları ve çalışma mantıkları

1. Mesaj Kutusu ve TextBox'a Yazı Yazdırma

private void button1_Click(object sender, EventArgs e)
{
    textBox1.Text = "Merhaba Dünya";
    MessageBox.Show("Merhaba Dünya");
}
  • textBox1.Text = "Merhaba Dünya"; : Form üzerindeki metin kutusunun içine yazı yazar.
  • MessageBox.Show("Merhaba Dünya"); : Ekrana açılır bir mesaj penceresi çıkarır.
  • MessageBox.Show(textBox1.Text); : Tırnak koymadan yazılırsa, metin kutusunun içine kullanıcının yazdığı metni mesaj kutusunda gösterir.

2. ListBox'a Eleman Ekleme ve Silme (Listeleme)

private void button1_Click(object sender, EventArgs e)
{
    listBox1.Items.Add(textBox1.Text);
    textBox1.Clear();
}
  • listBox1.Items.Add(textBox1.Text); : Metin kutusuna (`textBox1`) yazılan yazıyı alır ve liste kutusuna (`listBox1`) alt alta yeni bir satır olarak ekler.
  • textBox1.Clear(); : Ekleme işleminden sonra metin kutusunun içini temizler.
  • listBox1.Items.Remove(listBox1.SelectedItem); : Listeden fareyle seçilen satırı siler.
  • listBox1.Items.Clear(); : Listedeki tüm elemanları tamamen siler.

3. Koşul (if - else) ve Arka Plan Rengi Değiştirme

private void button1_Click(object sender, EventArgs e)
{
    if (textBox1.Text == "")
    {
        MessageBox.Show("Lütfen kutuyu boş bırakmayın!");
    }
    else
    {
        this.BackColor = Color.LightBlue;
        MessageBox.Show("Hoş geldin " + textBox1.Text);
    }
}
  • if (textBox1.Text == "") : Eğer metin kutusu boşsa uyarı mesajı verir. Karşılaştırma yaparken iki eşittir (==) kullanılır.
  • else : Kutu boş değilse çalışacak kısımdır.
  • this.BackColor = Color.LightBlue; : Form penceresinin arka plan rengini açık mavi yapar.

4. İki Sayıyı Toplama (Convert.ToInt32)

private void button1_Click(object sender, EventArgs e)
{
    int sayi1 = Convert.ToInt32(textBox1.Text);
    int sayi2 = Convert.ToInt32(textBox2.Text);
    int toplam = sayi1 + sayi2;

    MessageBox.Show(toplam.ToString());
}
  • Convert.ToInt32(...) : Metin kutusundaki yazıyı matematik işlemi yapabilmek için tam sayıya (int) çevirir.
  • toplam.ToString() : Bulunan sayısal sonucu mesaj kutusunda gösterebilmek için tekrar metne çevirir.
